LangChain Source Code Architecture

langchain-ai/langchain — Core + Classic + Partner Packages

langchain_core (libs/core)

  • • Base interfaces: embeddings, vectorstores, tools, prompts
  • • Schema definitions: Document, BaseMessage, AgentAction
  • • Abstract base classes for all integrations
  • • Language-agnostic core API

langchain_classic (libs/langchain)

  • • Concrete implementations: chains, agents, memory, retrievers
  • • chat_models, llms, document_loaders, output_parsers
  • • graphs (StateGraph, MessageGraph)
  • • evaluation, utilities, sql_database, storage

Partner Packages (libs/partners)

  • • 15 vendor-specific integrations
  • • LLMs: OpenAI, Anthropic, MistralAI, DeepSeek, Groq, Fireworks, Perplexity, xAI
  • • Embeddings/Vector: Chroma, Qdrant, Nomic
  • • Utilities: Ollama, HuggingFace, Exa, OpenRouter

Other Libraries

  • • text-splitters: standalone splitting algorithms
  • • runnables: unified execution primitive (RunnableSequence, Parallel, Branch)
  • • model-profiles, standard-tests, langchain_v1

Source: github.com/langchain-ai/langchain • langchain_core + langchain_classic + partners
